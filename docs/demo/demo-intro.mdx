# Intro to the Demo site

Installing an OS on a computer is a great step forward with a lot of difficulties. That's why a lot of people want to test an OS to be sure, that it's what they are looking for.

[This demo website](https://avdan-os.github.io/Demo/) is created to show the advantages of AvdanOS and to give an opportunity for the community to try its light version in a browser or launch it on a PC without any preparations.

That's why the demo website should be _lightweight_, _fast_, _multifunctional_ and _fail-safe_.

## What's inside

The Demo is a desktop environment that runs in the browser:

- **Windows** with several tabs each. Tabs can be reordered, merged into another window or detached into their own window. Windows snap to screen edges and can be resized, minimized and maximized.
- **A dock** with pinned apps, one underline per open tab, a clock, a mini music player and a tray.
- **A start menu** with weather, reminders, devices and pinned apps.
- **Four workspaces**, each with its own windows.
- **Apps:** Files, Music, Messages and Lale. Mail, Photos, Calendar, Notes and Settings are placeholders for now.
- **Three languages:** English, Romanian and Russian. The language is detected automatically.

## Built with

The Demo is written in **TypeScript** with [SolidJS](https://www.solidjs.com/) and built with [Vite](https://vite.dev/). The source code is on [GitHub](https://github.com/Avdan-OS/Demo).
